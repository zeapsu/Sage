# Sage Docs

Documentation is organized by purpose:

- [`product/`](product/) — product vision and direction.
- [`design/`](design/) — Ethereal Console/Tome Home design references.
- [`agent/`](agent/) — agent, skill, and UI contract docs.
- [`planning/`](planning/) — current session context and historical implementation plans.
- [`archive/`](archive/) — preserved legacy cleanup/reference notes.

For current product truth, start with the root [`README.md`](../README.md) and [`planning/session-context.md`](planning/session-context.md). Historical docs may describe older arXiv-first or implementation-plan states; status notes call that out where relevant.
