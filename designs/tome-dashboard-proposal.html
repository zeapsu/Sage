Dashboard as default, command bar as summonable power tool

Proposal for Sage's Tome-centric interaction model.

Great Sage thesis: the Dashboard handles common intent. The floating command bar handles expressive intent. Focus views handle deep work.

Answer to the command bar question

Yes, the command bar becomes secondary in the default flow, but not less important. It should function like macOS Spotlight or Raycast: summonable with a key command, always Tome-aware, and optimized for actions that are too specific for fixed buttons.

In normal use, the selected Tome opens to Dashboard. Press ⌘ K or click the small bar to invoke natural language and command search.

Three-layer model

  • TomeSelector: choose the knowledge scope.
  • Dashboard: glanceable, directly clickable overview of all common Tome workflows.
  • Focus view: one expanded component for chat, report, quiz, flashcards, audio, or sources.

Dashboard job

Dashboard should not auto-generate everything. It should show what exists, what is missing, what is stale, and what can be opened or generated with one click.

Command bar job

The command bar should answer questions like: “make this quiz harder,” “compare the latest report with source 3,” “generate a skeptical panel discussion,” or “find contradictions across these papers.”

Try the prototype

  • Drag a card by its handle to rearrange the Dashboard.
  • Drag the corner grip to resize a card across the responsive grid.
  • Click card content to switch focus views.
  • Click the compact command bar or press ⌘/Ctrl + K.
  • Use Reset layout to return to the Great Sage default.
